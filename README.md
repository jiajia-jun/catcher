# Catcher

把雨课堂、学习通、学在重邮的作业抓取到一个本地桌面窗口里，不用来回切网页。

当前版本 **1.1.0**。学在重邮为实验性功能，只支持导入浏览器 session。

## 功能

- **雨课堂**：扫码登录，抓取课程与作业
- **学习通**：手机号 + 密码登录，抓取课程、作业与详情页截止时间
- **学在重邮**：导入浏览器 session，抓取当前学期课程与作业（实验性）
- 作业表统一展示平台、课程、状态、截止时间与时间来源
- 「只看本学期」按 9 月 1 日划线，可在工具栏随时切换
- 按平台刷新，支持取消与进度显示；单个平台失败不影响另一个
- 登录态失效时自动续期一次（雨课堂重放凭证，学习通用保存的密码重登）
- 启动后检查新版本，发现更新时提示并打开 GitHub 发布页
- 所有数据只保存在本机，不上传任何服务器

## 安装

系统要求：Windows 10/11 x64，需要 WebView2 Runtime（安装器会自动处理）。

### 安装器

下载 `Catcher-1.1.0-amd64-installer.exe` 运行。安装器默认装到当前用户目录，**不需要管理员权限**，也可以在安装页改成任意当前用户可写的目录（包括 D:、E: 等非系统盘）。

> 安装目录必须对当前用户可写。`Program Files` 这类目录普通用户无法写入，安装器会拦下来并提示换一个位置。

### 便携版

下载 `Catcher-1.1.0-portable.zip`，解压到任意可写目录，运行 `Catcher.exe`。

### 卸载

卸载程序会询问是否一并删除数据。选择保留时，作业记录、登录态和日志会留在安装目录的 `data/` 里，重新安装到同一目录即可继续使用。

安装目录本身不会被删除：即使选择删除数据，也只移除程序文件，目录保留在原位。

## 数据目录

默认是 exe 同级的 `data/`。也可以用以下方式指定：

1. 命令行 `--data-dir <path>`
2. 环境变量 `CATCHER_DATA_DIR`

目录不存在会自动创建；不可写时显式报错，**不会回退到 C 盘或临时目录**。

```text
data/
├── catcher.yaml
├── catcher.db
├── catcher.db-wal
├── catcher.db-shm
└── logs/
    └── catcher.log
```

建议安装在本地磁盘。网络盘、映射盘上 SQLite 的文件锁不可靠，可能导致数据损坏。

## 安全与隐私

- 程序不监听任何本地端口，也不在后台起服务，只有主动发出的出站请求
- 雨课堂与学习通走 HTTPS；学在重邮的校园站点只开放 HTTP，session 在该站内为明文传输
- 登录态与学习通密码使用 Windows DPAPI 加密后存入本地 sqlite，只对当前 Windows 用户可解密
- 日志不记录 Cookie、Set-Cookie、Authorization、密码、token 或二维码内容
- 更新检查只向 GitHub 查询最新版本号，请求只含客户端版本号与常规 HTTP 头，不携带账号、作业或日志数据
- 数据**不会上传到任何第三方服务器**

## 已知限制

- **设置项目前是只读的**：日志级别等在 `data/catcher.yaml` 中，修改后需要重启；界面暂不支持修改
- **学在重邮为实验性功能**：只支持导入浏览器 session，session 约 24 小时，失效后需重新导入；不支持 CAS 自动登录。导入与当前学期抓取已在真实环境跑通，session 轮换、翻页边界尚未验证
- **失败响应留底未实现**：设置里显示的状态暂时不产生实际行为
- 雨课堂的扫码登录与课程抓取已验证；`type=20` 作业字段、部分续期场景依赖平台实际返回
- 学习通的部分翻页场景和加密参数过期后的表现尚未覆盖
- 安装包与程序**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」

## 从源码构建

需要 Go 1.27、Node 24、Wails v2.13。

```bash
wails build            # 产物 build/bin/Catcher.exe
wails build -nsis -installscope user   # 额外生成用户级安装包（需要 NSIS）
```

开发模式：

```bash
wails dev              # 前端热更新，数据写到仓库根目录 data/
```
